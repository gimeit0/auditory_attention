## 1. 论文实际怎么训练的（从 Methods 核实）

### 1.1 训练数据规模
- **3,973,192 条样本**，每条 = cue + 多源 mixture + 词标签。
- cue/target/distractor 语音来自 **Common Voice v9 英语 train split**。
- 筛选：Wav2Vec2 强制对齐 → 只留 44.1kHz → 词长 ≥5 字符且 ≤2s → 每词 ≤5000 例 → 取最多的 **800 词** → 重采样到每词 5000 例（3,994,484 条）→ **excerpt 级性别平衡**（男女各 496,649）→ 993,298 条单词样本。
- 每个 target 被采样 **4 次**（各进不同场景）。

### 1.2 噪声与空间化（关键难点）
- **非语音干扰**：AudioSet（筛掉 Music/Speech/Singing 等，≥9s 父片段）→ 训练 661,877 个父片段。
- **空间化**：Saddler & McDermott 的房间模拟器（image-source 法 + **KEMAR HRTF**），**2000 个房间**（1800 训 / 200 验），每房 1584 个声源位置 → **2,851,200 个训练位置**。
- 场景生成：采 target → cue（同人不同词）→ 干扰源数 1–6（其中 talker 数 0–n，其余取 AudioSet）→ 各源电平在 20dB 范围内采样 → **一半场景干扰与 target 同位置、一半随机位置** → 空间化后逐通道求和。

### 1.3 增强与边界
- 50% 样本对 cue 或 target 加 Butterworth 带通（低截 40–400Hz、高截 4–16kHz、阶数 1–4）。
- target 随机时移（0–50% 词长，保证词仍跨中点）。
- mixture 在线混音，**SNR 均匀采样 −10…+10 dB**。
- cue 和 mixture **RMS 归一到 0.02**。
- **10% 样本无 cue**（单说话人 + 静音 cue），让模型学会报孤立词。
- 所有信号切 2.5s → 过耳蜗 → 取中间 2s。

### 1.4 优化
- **AdamW**，**lr 5e-5**，**batch 288**，**4×A100**（DDP），16 CPU、100GB 内存，**约 10 epoch**（验证集收敛为止）。
- 13 个架构 → 训练后按验证集选 **top 10** → 结果取 10 个平均。`arch_v00` 是最优架构（来自 Saddler & McDermott 2024）。

### 1.5 耳蜗前端（固定，不训练）
40 通道 gammatone（40Hz–20kHz）→ 半波整流 → ^0.3 压缩 → 4kHz 低通降采样到 10kHz → 中间 2s。输出 **2 通道 × 40 频 × 20000 时**。

## 3. 现实差距分析

要"完整忠实训练"，缺的是：
1. **数据生成管线**（作者未公开）——最大的坑。
2. **AudioSet**（非语音干扰）——数百 GB 下载 + 筛选。
3. **房间模拟器 + KEMAR HRTF**（空间化）——另一个大工程（Saddler & McDermott 的独立系统）。
4. **算力**：4×A100 训 ~10 epoch on 4M 样本。HAKUSAN 单卡 A100 约慢 4 倍，忠实全量要**数周**。

**结论**：把"完整忠实训练"当第一步 = 撞墙。**必须分层。**

## 4. 分层方案（推荐从 Tier 0 起）

### Tier 0 —— diotic 语音训练（推荐的第一个真实验）

**思路**：你要复现的 Experiment 1 全是 **diotic**。既然如此，**训练也做 diotic**——直接砍掉空间化（房间/HRTF）整条管线。训练数据用**你已经建好的评测管线**来造（align → 选锚点 → 切 2.5s → 混音 → RMS 0.02 → DuplicateChannel）。

#### 为什么可以整个跳过空间化（关键论证）

空间渲染子系统（房间模拟器、KEMAR HRTF、2000 房间、1584 声源位置）**只为支撑论文的空间实验（Fig 3/4）**存在，而本项目明确不做空间实验。可以整个跳过，理由有三：

1. **评测本来就无空间线索**：Experiment 1 全程 diotic（L=R），输入里根本没有 ITD/ILD 可用，训练教不教空间线索对 diotic 任务无关。
2. **架构不依赖空间**：现在推理用的作者 checkpoint，评测时就是 `DuplicateChannel` 喂 diotic 输入、跑得正常 → diotic 对该模型是**分布内**，砍掉空间化不会让模型崩。
3. **论文自身的证据**（Methods, p.948 场景生成）：
   > "为防止模型只靠定位线索，**一半的训练场景把干扰源放在与 target 相同的位置**；另一半才随机放置。"
   即作者**故意**让一半场景**没有空间分离**，逼模型用**声音特征**（音高/音色）分离目标与干扰——而这正是 Experiment 1 考察的能力。**diotic-only 训练 = 把训练全部集中在论文那"共位一半"、最考验声音特征选择的 regime 上**，与本项目的评测目标高度对齐，而非冲突。

> **两个独立的轴，勿混淆**：**空间化**（房间/HRTF/位置）和 **AudioSet 非语音干扰**是两回事。前者对 diotic 目标**不需要**、直接跳过；后者取决于忠实度——第一轮可只用**语音干扰**，AudioSet 之后再加（本项目复现重点"性别 / 干扰数量"本就都是语音干扰）。

> **诚实边界**：diotic-only 训练 ≠ 论文训练（论文是"空间 + 共位"混合 regime）。因此只能声称 **"feature-gain 机制能否仅从 diotic 语音训练中涌现"**，**不能**声称复现了论文那个含空间能力的完整模型；汇报写成 **"diotic-trained, single-architecture"**。

**这一步回答的科学问题**：feature-gain 选择性听取机制，能否**仅从 diotic 语音混合训练中自发学出**？训出来的模型在 Experiment 1 上是否也复现"SNR↑准确率↑、异性>同性、人越多越难"？

- **数据**：Common Voice v9 **train split**（≠ 你评测用的 validated split，避免泄漏）。
  - 复用 `align_words.py` + `build_distractor_pool.py` 的逻辑批量造 (cue, mixture, label)。
  - 干扰：先只用**语音干扰**（1–4 talker，diotic 求和），SNR 在线采样 −10…+10。
  - 规模：起步 **~50 万–100 万条**（不是 4M）。够学出机制、又能在单卡几天内跑完。
  - 10% cue-free（照论文）。
- **模型**：只训 **1 个架构**（`arch_v00`，作者的最优架构），不做 10 架构平均。
- **算力**：HAKUSAN **单卡 A100**（`-p GPU-1A`），batch 按显存调（288/GPU 在单卡可能要降到 64–128 或用梯度累积）。
- **产出**：一个自训 checkpoint → 喂进你现成的 `snr_scan.py` / `snr_scan_multi.py` → 和作者 checkpoint 的趋势对比。

**判据**（成功 = 趋势方向对，不看绝对数）：自训模型在 Experiment 1 上也给出单调 SNR 曲线、异性>同性、人越多越难。**能复现 = 强证据：机制是训练目标的自然产物，不依赖作者的具体数据/空间化。**

### Tier 1 —— 加 AudioSet 非语音干扰
在 Tier 0 基础上，干扰源加入 AudioSet 噪声（照论文 1–6 源、0–n talker）。需下载筛选 AudioSet。仍 diotic。

### Tier 2 —— 忠实空间化训练（大工程，暂缓）
补房间模拟器 + KEMAR HRTF + 完整场景生成，重建 4M 空间化数据集，多卡训 10 架构。**这是独立的数月级项目**，且需要作者未公开的管线代码或自行重写。**当前不做。**

## 5. Tier 0 具体怎么跑（可执行步骤）

> 全部在 **HAKUSAN GPU 节点**上做（本地 M1 训练不现实）。

### 步骤 1 — 建立训练锚点目录（已实现）

现在不再预先生成 HDF5。`selftrain/scripts/build_anchor_catalog.py` 只保存较小的词级锚点目录，`selftrain/data/diotic_attention.py` 在训练时在线组合新的 cue、target 和 distractor：

```
对 CV v9 train split:
  排除既有评测说话人 → MMS 强制对齐 → 选表内锚点词
训练时:
  cue = 同说话人、不同录音、不同锚点词
  target = 以锚点词为中心的 2.5 秒
  distractor = 1..4 名不同说话人的 2.5 秒语音
  在线采样 SNR → RMS 0.02 → DuplicateChannel (L=R)
```

这样不会把同一录音组合重复保存数十万次，也能让每个 epoch 产生新的随机混合。

### 步骤 2 — 配置（已实现）

- 冒烟配置：`selftrain/configs/smoke.yaml`
- 正式配置：`selftrain/configs/full.yaml`
- 正式配置从随机权重开始，AdamW、lr 5e-5、500,000 个在线样本/epoch、最多 10 epoch、验证早停。
- 初始 GPU batch 为 32、梯度累积为 2；先在 A100 上观察显存，再决定是否调整。

### 步骤 3 — 冒烟训练（已通过）

```

  --config selftrain/configs/smoke.yaml \
  --exp_dir selftrain/experiments --gpus 0 --n_jobs 0 --precision 32-true
```

本地已确认：800类前向输出正常、51组参数获得有限梯度、权重更新、训练/验证和 checkpoint 保存均成功。

### 步骤 4 — 扩大目录并正式训练

本地上传：

```

```

## 7. 主要风险与诚实边界

1. **数据格式对齐是最大不确定性**：必须先逆向 `corpus/binaural_attention_h5.py` 的 HDF5 字段。若格式复杂（存的是预算好的耳蜗图而非波形），造数据成本会上升。
2. **diotic 训练 ≠ 论文训练**：论文训练含空间线索和 AudioSet 噪声。自训 diotic 模型即使复现 Experiment 1 趋势，也**只能声称"机制可从 diotic 语音训练中涌现"**，不能声称复现了论文的完整模型。
3. **单架构 ≠ 论文的 10 架构平均**：结论要限定为 single-architecture。
4. **lr 口径**：config(5e-6) 与论文(5e-5) 不符，需实测选定。
5. **可复现性**：训练要冻结 seed、环境、数据 SHA、命令，否则结果不可重跑。
6. **不保证复现**：这本身是个开放实验——训不出效应也是有信息量的结果（说明机制依赖论文的数据/空间化设计），如实报告。
