## 4. 检查动态数据集

```bash
python -m selftrain.scripts.check_dataset --batch-size 2
```

必须看到：

```text
Diotic dataset checks: PASS
```

该检查同时验证：

- cue和target说话人相同；
- cue和target不是同一录音或同一个锚点词；
- 干扰说话人不包含target说话人；
- 干扰说话人不重复；
- 左右声道完全相同；
- 标签在0–799范围；
- cue-free样本构造正确。

## 5. GPU smoke test

先在A100上运行最小随机初始化训练：

```bash
python -m src.spatialtrain \
  --config selftrain/configs/smoke.yaml \
  --exp_dir selftrain/experiments \
  --gpus 1 \
  --n_jobs 0 \
  --precision 16-mixed \
  --random_seed 20260721
```

通过标准：

- 没有OOM；
- 没有NaN/Inf；
- 能完成train和validation；
- 能生成自训练checkpoint；
- 日志没有载入作者checkpoint。

smoke通过后还要用batch=32测量正式配置显存与吞吐。记录100个batch的平均时间，据此
估算：

```text
每epoch batch数 = ceil(500000 / 32) = 15625
epoch预计时间 = 平均batch秒数 × 15625 + validation时间
```

如果预计超过约20小时，先修改epoch划分和checkpoint策略，不要直接启动24小时正式
作业。

## 8. 中断后恢复

先确认`last.ckpt`存在且时间正确：

```bash
ls -lh selftrain/experiments/full/checkpoints
```

再提交：

```bash
RESUME=1 sbatch selftrain/hakusan/run_training.sbatch
```

日志中必须出现恢复checkpoint路径，并且global step应从上次继续，而不是从0重新开始。

如果没有任何checkpoint，不能使用`RESUME=1`；需要先确认为什么上一个作业在保存前
结束。

## 9. 作业结束后的检查

```bash
sacct -j JOBID \
  --format=JobID,State,Elapsed,MaxRSS,AllocTRES,ExitCode

find selftrain/experiments/full/checkpoints \
  -maxdepth 1 -type f -name '*.ckpt' -ls
```

确认：

- 作业状态为COMPLETED，或中断原因已记录；
- best和last均存在；
- 预定阶段checkpoint存在；
- metrics中没有NaN；
- 最终epoch和global step与记录一致。

## 10. 下载小型结果

## 11. 进入评测

正式训练完成后，按方案书选择stage 0、中间epoch、best和last，依次运行：

1. clean/cue-free识别；
2. 性别条件复现实验；
3. 多话者数量复现实验；
4. 双耳任务探索性评测。

评测前冻结刺激清单，不能为不同checkpoint重新随机生成刺激。
