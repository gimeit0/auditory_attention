# 任务2：全量自训练实验

**建立日期：2026-07-23**
**实验ID：`task2_diotic_full_20260723_seed20260721`**

这个目录对应2026年7月21日会议记录中，在双耳任务之后提出的“自己训练模型”任务。

任务2的主线是：

1. 不载入作者公开checkpoint；
2. 使用自己的Common Voice训练数据，从随机权重训练feature-gain模型；
3. 保存训练过程中的模型阶段；
4. 用与前两个复现实验及双耳任务一致的评测方法检查模型；
5. 为之后比较模型训练轨迹与人的发达数据建立基础。

## 当前采用的实验范围

当前可执行的正式实验是：

> **单架构、diotic、语音干扰、随机初始化的全量自训练。**

这里的“全量”是指按照`selftrain/configs/full.yaml`进行正式训练，最多在线采样
500,000条/epoch × 10 epoch，而不是论文未公开的完整空间化训练管线。

论文训练还包含房间模拟、KEMAR HRTF、残响、AudioSet非语音噪声和多个架构。
这些条件目前不能忠实重建，因此本实验不能表述为“完整复现论文训练”。
