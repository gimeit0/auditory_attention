## 4. 10,000 个 scene 如何构造

正式 bank 使用固定 seed `20260815`，从冻结的 validation anchors 预先生成 10,000 个互不重复的 scene。每个 scene 包含：

- 一个 target utterance；
- 一个与 target 不同 speaker、不同 label 的 distractor utterance；
- 一个 target-speaker 的正确 cue，且 cue 使用不同录音、不同词；
- 一个 distractor-speaker cue，同样使用独立录音和不同词；
- 一个从完整 correct-cue 池做受约束置换得到的 shuffled cue。

正式配置强制：

- 恰好 1 名 distractor；
- target 与 distractor 为标称 0 dB；
- `cue_free_percentage=0.0`；
- `mask_cues=false`；
- target、distractor 和各 cue 的 speaker/path/word/label 关系通过 manifest validator。

`shuffled` 不是随便从另一种分布抽一段音频，而是对完整 correct-cue 池做约束置换，因此整体 cue 边际分布保持一致，同时 donor 不能是本 trial 自身，也不能匹配当前 target/distractor 的 speaker 或词。

## 5. 每个 scene 实际做了什么

对每个 batch（batch size 16），评估器执行：

1. 读取 target、distractor 和三种非静音 cue 的音频；
2. 以训练时相同的 transform 对 target 与 distractor 做标称 0 dB 混合；
3. 生成一次固定的双通道 scene，并记录该 scene 的 SHA256；
4. 分别准备四种 cue：
   - `correct`：target-speaker cue；
   - `shuffled`：受约束置换后的不匹配 cue；
   - `silent`：全零 cue；
   - `distractor`：distractor-speaker cue；
5. scene 的耳蜗表征只计算一次，四个条件完全复用；
6. 每个条件只替换 cue 表征，然后执行冻结 CNN 的前向推理；
7. 保存预测 label、是否命中 target、是否误选 distractor、target/distractor 概率和 target negative log-likelihood。

因此这是 10,000 个固定 scene 的四条件配对比较，相当于 40,000 个 cue-condition 推理，但不是 40,000 个互不相关场景。scene 在四个条件间保持逐字节一致，唯一实验操纵是 cue。

模型以 `eval()`、`torch.inference_mode()` 和 FP16 autocast 运行，参数被冻结。评估结束还检查所有模型参数的内部版本没有变化，并拒绝任何 NaN/Infinity。


## 9. 科学解释

最保守、可由数据直接支持的结论是：

> 在冻结的 validation-speaker、单干扰者、标称 0 dB scene 上，Job 551219 模型的目标选择强烈依赖 voice cue 与目标声源的正确对应关系。

证据不只来自 silent cue。更有信息量的 shuffled 对照保持了 correct-cue 池的整体边际分布，但破坏了 cue 与当前 target 的对应关系；accuracy 仍从 44.97% 降到 15.96%，配对差为 29.01 个百分点。

另外，当 cue 指向 distractor speaker 时，模型预测 distractor label 的比例由 1.45% 上升到 42.21%。这说明 cue 能够系统性地把模型选择从 target 推向 distractor，属于很强的因果方向性证据。

该验证已经解除“模型是否利用 cue”的阶段门禁，可以进入 full-distribution pilot。

## 10. 仍需保留的限制

- 这是训练期间使用过的 validation anchor pool 上的机制诊断，不是最终 untouched test；
- 只评估 1 名 distractor、标称整段 0 dB、单个训练 seed 和单个 checkpoint；
- `silent` 是强退化输入，极大的 cross entropy 不宜单独作为主要证据；主要结论应以 correct-vs-shuffled 的配对结果为主；
- 结果证明模型利用 voice cue 选择声源，但不能仅凭本实验区分它利用的是精细 speaker identity，还是性别等较粗粒度的声音特征；
- 该任务不评估 1--4 distractors、−10 至 +10 dB 的完整训练分布，也不能预测 full 的最终 accuracy；
- `CONFIRMATORY_PASS` 只放行 4 轮 full-distribution pilot，不等于直接放行完整 40 轮训练。
