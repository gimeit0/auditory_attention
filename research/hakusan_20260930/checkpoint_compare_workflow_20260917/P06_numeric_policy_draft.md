## 1. 政策条款

### P06-1 固定配置：逐位一致，无容差

同一冻结包、同一 checkpoint、同一布局清单、同一 batch 分段、同一设备型号（A100）下，任何重复运行的 logits 必须 **逐位相等**。不满足即 `EXECUTION_INVALID`，停止并调查实现问题；不得用容差吞掉。

全量运行内置的自检：正式 10k 运行完成后，对预先固定的 32 条（原 O 集合）在同一作业的新进程中重跑一次，与全量产物中对应 trial 的 logits 逐位比较。这是全量作业的一部分，不额外增加作业数。

### P06-2 批内串扰：零容忍

同伴重排后 correct cue 逐位一致已被验证一次（726428）。全量运行不再重复该检查，但若 P06-1 的 32 条重跑在不同同伴环境下与全量产物不一致，同样视为 `EXECUTION_INVALID`。

### P06-3 批形状扰动：记录并有界，不是通过/不通过阈值

正式运行 batch 固定为 16。10,000 与 2,000 均能被 16 整除；若执行器按条件连续分批则不产生尾批。实际分段必须写入回执；出现任何部分批时，其影响以已测尾批效应（NLL ≤1.3e-4）为参考记录，不阻断。

**扰动包络（envelope）**：NLL 绝对差 2e-3、logits 绝对差 4e-3（约为已观测最大值的两倍）。它是**报告用的敏感性区间**，用于 P06-4/5 的推导，不是用来判 PASS 的数；全量运行不会也不能重新测量它。旧 `1e-6` 检查继续作为历史输出保留并标注 DIFF，报告中明确说明它是针对固定配置的检查，对跨批形状比较不适用。

### P06-4 预测翻转：按 margin 分层报告，不假设为零

- 全量产物中，每个模型—条件按 top1−top2 logit margin 分层统计：`margin ≤ 4e-3`（包络内，翻转“可能”）、`4e-3 < margin ≤ 4e-2`、`> 4e-2`。
- 报告每层 trial 数与比例。**Accuracy 的数值不确定性上界 = 包络内层的比例**；该上界与 bootstrap CI 并列报告。
- 32/17 条上 0 翻转**不得**外推为全量 0 翻转。
- 若包络内层比例 > 主要 Accuracy 结论所需分辨率（例如 formal40 与 author 的 Accuracy 差小于该比例），报告“数值不足以分辨 Accuracy 差”，并以 NLL 作为主要连续指标。

### P06-5 误差预算与效应量

- NLL 主表：数值扰动对配对均值差的贡献上界取包络 2e-3（保守：每条 trial 同向最大扰动）。要求它 **< 配对 bootstrap 95% CI 半宽的 1/10**；满足则在报告中声明“数值扰动可忽略”，否则把包络作为附加不确定性明确写入。
- 该判断在看到全量 CI 后按上述固定规则机械执行，不引入新阈值。

### P06-6 全量运行的硬停止条件（与 P08 验收一致）

非有限值、strict-load 覆盖率 ≠1.0、eval 状态变化、输入身份不符、AllocTRES 非 1×nvidia_a100、P06-1 自检不一致。任一出现即停止，不解释部分产物。

### P06-7 本政策不决定的事

主 checkpoint、数据、主指标、bootstrap 规则、研究身份 `REUSED_VALIDATION_BANK_AUDIT_NOT_INDEPENDENT_TEST` 均沿用科学合同；不得根据全量结果反向修改。

## 2. 在额外确认集 / P07 上的预注册验证（进入全量前）

建议与 P07 约 256 条成本测量合并为一个作业（预算另批）：

1. 256 条按原 bank 分层（clean/mixed、干扰数、SNR、control_subset）用固定 seed 预先选定，排除原 O 集合，清单与 SHA 在看结果前冻结。
2. 正式路径 batch16 跑 256 条；同一作业中新进程对其中固定 32 条子集跑 batch1。
3. 预注册判据：(a) 256 条中固定 32 条子集与 batch16 产物对应 trial 的 batch16 重跑逐位一致（P06-1）；(b) batch16/1 的 NLL、logits 差落在包络内；(c) 按 P06-4 分层统计并报告。
4. (b) 超出包络时不放宽包络，而是停止并调查；只有明确找到实现原因并修复后才重新验证。

## 3. 决定点（已全部按草案审定）

1. 包络取观测最大值的 2 倍（NLL 2e-3 / logits 4e-3）是否接受。
2. P06-4 的 margin 分层边界（4e-3 / 4e-2）是否接受。
3. P06-5 的“< CI 半宽 1/10”规则是否接受。
4. 是否同意把额外确认集与 P07 成本测量合并为一个作业。
5. 全量作业内置 32 条逐位自检（P06-1）是否同意。
