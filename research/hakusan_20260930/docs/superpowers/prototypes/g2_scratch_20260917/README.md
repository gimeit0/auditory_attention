## 修正的问题

固定 `g2_worker_20260916/cell_bridge.py` 的生产分支要求
`type(scratch) is diag._WorkerScratch`。但原 `_WorkerScratch.check` 要求 `HOME`
指向临时目录，而已有的保留真实 HOME 的候选使用另一个类型。直接组合会被拒绝。

本候选保留原文件不变，仅在独立命名空间中派生：

- 原目录工厂改用 G2 的 profile/side 名称和 `audattn_g2_JOB` 父目录。
- 原目录检查使用除 HOME 外相同的十项缓存环境路径，另检查真实 HOME 未变。
- 原 bridge.run 仅替换一次精确类型比较，仍要求本 binding 当前持有的独占临时目录。
- AST 反向替换必须完整还原原函数；推理函数、spill/mmap、状态/输入检查、容差和异常撤销保留。

所有数值库导入必须在目录 scope 建立后。绑定对象单进程、单次使用，失败不能重入；
原目录 fd/所有者/0700、挂载检查、独占创建和文件保留策略不删除。不会创建或赋值 HOME。
