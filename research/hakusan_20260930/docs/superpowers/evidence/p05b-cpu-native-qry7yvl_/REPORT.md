## 交付

`same_bank_compare_2026_09_18_layout_v1/offline_review.py` 提供单一离线入口：

1. 验证外部 release、终态与 status 证据 SHA；冻结包完整源码、job ID和契约身份一致。
2. 完整文件集合/大小/SHA与终态记录一致；原始归档只读，输出独占新目录。
3. 核对 Slurm COMPLETED/0:0及节点、四模型进程独立和八个模型/验收步骤顺序。
4. 四份归档从 logits 独立重算，并按固定 receipt 读取旧725677的两份基线。
5. 汇总7组对照，保存每组JSON、paired_nll.csv和REPORT.json；校验已保存的review摘要确实等于本次重新计算结果。
6. 固定设置冷重复不一致仍停止；跨batch/布局数值差异保留。失败作业只登记失败，绝不自动解释为资格通过。

`control.py` 的正式文件集合已加入此离线入口，未来冻结包会绑定其SHA。未修改科学推理核心、模型、bank、数值阈值或旧结果。
