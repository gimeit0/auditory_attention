## 2. 有界2×2矩阵

每格单独冷进程、独立空缓存、strict-load同一formal40；同一cell内先batch16再batch1。
每pass都完整32条，即2+32=34次模型调用/cell，不重置模型/RNG/缓存来掩盖两轮差异。
AMP始终关闭，不引入TF32以外的混合精度变量。正确cue为本阶段唯一条件；另外三种control在G4测。

| 顺序/名字 | CUDA matmul TF32 | cuDNN TF32 | matmul precision实际读回期望 | compile |

| R（旧B2设置的新运行） | true | true | high | 按旧模型编译路径 |
| C | false | false | highest | 同R |
| D | true | true | high | 禁用目标编译包装，使用同一底层模型 |
| E | false | false | highest | 同D |

所有格保持deterministic_algorithms=true、cudnn.deterministic=true、cudnn.benchmark=false；
seed20260829，CUDA初始化前配置 `CUBLAS_WORKSPACE_CONFIG=:4096:8`。
六项实际读回、AMP实际状态、dtype、eval状态和参数冻结必须记录并校验。

compile开/关实现需先核对实际冻结模型源码的编译位置、wrapper及后端；不能只改一个未被消费的CLI参数。
不能全局monkeypatch `torch.compile`、修改旧模型文件、冒用旧loader身份或把意外eager回退称为编译对照。
新适配器必须给出目标编译对象的明确映射、底层参数/模型对象绑定、冷缓存和后端进入证据。

## 3. 保存什么，不额外扩张什么

每cell保留：加载报告/完整来源、实际运行设置、两pass的32条身份/原始输入摘要、
归一化及特征摘要、32×800 logits和log概率、pred_label/NLL/p_target/p_probe、
前/中/后状态和RNG检查、编译状态、阶段耗时/内存/显存峰值、成功或失败终态。
摘要需包含dtype/shape及逐trial内容哈希，不比较带batch维度的整体哈希来误判跨batch变化。
不默认记录全部42位置中间张量；仅为本对照必要的输入/输出边界取证。
任何新增采集点先做端点/状态/RNG干扰验证，失败不用于解释层级根因。

每cell报告max/median/p95/p99绝对差、超过1e-6数量、预测类别翻转数及对应margin；
logits差异用于诊断，不偷偷把旧官方指标canary阈值扩成另一条新规则。
不得将32条诊断“类别相同”写成32条“预测全对”。

## 4. 判定和停止条件

将两层判定分开：

- **执行证据有效性**：身份/来源/顺序/输入/状态/RNG/设置、有限值、自洽、完整工件和独立重验通过。
- **数值接受**：正确cue官方输出NLL/p_target/p_probe的16/1最大绝对差≤1e-6；pred_label和身份完全一致。
  NaN/Inf不作为可跳过值；相对误差不替代这一绝对标准。

有效但数值不同是 `NUMERIC_DIFF`，不是执行异常：继续原定矩阵余下格，不增加组合。
缺工件、加载/状态/来源异常、超时、非有限值、错误设置是 `EXECUTION_INVALID`：立即停止，余格标记NOT_RUN。
初始矩阵全部有效后，候选优先顺序预先固定 **E → C → D → R**：
优先TF32关闭、无额外编译的简单执行方式，不按准确率高低挑配置。
没有任何格达到旧接受条件，则本规格不允许放宽1e-6或直接进入10k。

入选后另做两个独立冷进程，每个同一设置、batch16、32条，加载/缓存隔离；
比较两冷启动输出及矩阵对应batch16输出。仍采用官方指标≤1e-6、类别/身份一致和有效性条件，逐位一致另外报告。
若入选设置失败，先分析，不自动尝试下一优先项直到碰巧成功。
这只是formal40设置候选，尚须G4三模型/controls在新正式路径上的验收。

仍无可接受设置：写一份独立协议修订申请（误差预算、固定batch策略、独立确认样本、成本），
或最多先提一项有明确假设的定点诊断；不得看完10k排名后改标准。
