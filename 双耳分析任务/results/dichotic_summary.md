# Dichotic-listening evaluation summary

- Valid trials: 440 (speakers: 110)
- Dichotic exact hit: 347/440 = 78.9% (95% Wilson CI 74.8%–82.4%; speaker-bootstrap CI 73.4%–84.1%)
- Opposite-ear word: 0/440 = 0.0% (95% Wilson upper bound 0.9%)
- Other word: 93/440 = 21.1%
- Routing fidelity conditional on a presented-word response: 347/347 = 100.0% (95% Wilson lower bound 98.9%)
- Matched-level monaural correct: 70.7% (95% Wilson CI 66.3%–74.7%)
- Standard diotic-clean correct: 89.1% (95% Wilson CI 85.8%–91.7%)
- Left-cued vs right-cued hit: 79.5% vs 78.2%

## Paired descriptive checks

- Dichotic / diotic-clean contingency: both correct 339, dichotic only 8, diotic only 53, neither 40.
- Among the 392 trials recognized in the standard diotic-clean condition, dichotic accuracy was 339/392 = 86.5%.
- Target-matched left/right outcomes (220 targets): both correct 165, left only 10, right only 7, neither 38.

## Interpretation

Routing fidelity and absolute word recognition are separate. Zero opposite-ear responses strongly supports correct ear selection, but 78.9% absolute accuracy does not meet the adult-near-100% criterion. The diotic-clean comparison shows both baseline recognition errors and an additional dichotic cost. The unilateral monaural condition is an input-format control, not an upper bound: its silent second channel differs from the binaural input distribution used to train the model.
