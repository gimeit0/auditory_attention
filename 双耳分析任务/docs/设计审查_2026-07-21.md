# 双耳分听任务设计审查

**日期：2026-07-21**

## 结论

现有工作在研究方向上是合理的：左右耳放同一说话人的不同语音、cue只放目标耳、左右互换，
与会议中确定的任务一致。20人探针得到72.5%命中和0%对侧词，支持模型能够利用cue耳进行
路由，因此继续建立正式评估集是合理的。

但是，旧结果只能说明“路由机制初步可行”，不能说明“模型已达到成人水平”，任务1还不能
判定完成。正式评估必须把耳路由和词识别上限分开。

## 与会议要求的对应

| 会议要求 | 审查结果 |
|---|---|
| 左右耳为同一说话人 | 已满足 |
| 左右为不同语音/不同词 | 已满足；正式清单进一步要求不同录音 |
| 分别cue左耳和右耳 | 已满足 |

## 旧探针中需要修正的地方

### 1. 总命中与路由正确率不能混为一谈

旧结果为：

- 总命中：58/80 = 72.5%，95% Wilson CI约61.9%–81.1%；
- 对侧词：0/80，95%区间上界约4.6%；
- 在模型回答两耳呈现词之一的58次中，58次都回答cue耳词；条件路由率58/58，95%区间约
  93.8%–100%。

所以路由证据很强，但绝对词识别仍低于成人参照。

### 2. “其他词”不能直接全部归因于词识别错误

旧探针没有用同一target/cue测试无对侧语音时的表现。27.5%的其他回答可能来自：

- 该target词本来就难以被checkpoint识别；
- 单耳呈现偏离训练分布；
- 双耳同说话人竞争造成额外损失；
- 切片或cue质量。

因此正式评估新增“同耳单声源”和“标准diotic clean”两个匹配基线。

### 3. 随机基线表述需要限定

模型是800分类，总体exact随机命中率约0.125%，不是50%。50%只表示：在已经确定模型回答
左右两个呈现词之一的前提下，随机选择cue耳词或对侧词的概率。

### 4. cue RMS需要按双耳全局口径处理

旧脚本把单耳cue活动通道归一到0.02，另一通道为0，所以双耳全局RMS为
`0.02/sqrt(2)≈0.0141`。作者的双耳预处理对两个通道整体归一到RMS 0.02，因此正式脚本将
单耳cue整体归一到0.02，活动通道RMS约0.0283。

左右目标语音仍各自RMS 0.02；两侧同时存在时，双耳全局RMS也是0.02。

### 5. 可用说话人数曾被高估

“136人”只表示至少有两个trial/锚点，并不保证有两条不同target录音和第三条独立cue录音。
严格核查为：

- 119人具有两条不同target录音和不同目标词；
- 从Common Voice元数据补选第三条cue后，110人满足全部条件；
- 正式设计为110人×4 trial=440 trial。

## 已完成的继续工作

1. `build_dichotic_manifest.py`：生成严格、确定、不看模型结果的正式清单；
2. `run_dichotic_eval.py`：同时运行双耳、同耳单声源和diotic clean三条件，保存逐trial预测和
   目标/对侧词概率，支持`--resume`；
3. `analyze_dichotic_results.py`：计算命中、对侧混淆、其他词、条件路由率、左右耳结果和
   Wilson 95%区间，并输出图；
4. 已生成110人/440 trial清单；
5. 已完成8条端到端smoke，三种条件均为8/8正确。该结果仅验证管线，不作为正式结论。

## 下一判据

正式结果应至少回答：

1. 双耳exact命中率是否接近成人的高水平；
2. 对侧耳词比例是否仍接近0；
3. 双耳命中相对同耳单声源和diotic clean下降多少；
4. 左右cue条件是否存在稳定差异；
5. 若双耳成绩不高，问题主要是基线词识别失败还是双耳竞争损失。

在这些结果出来前，最严谨的表述是：

> 同说话人双耳分听的输入构造和cue耳路由已经通过初步验证；正式评估管线与440条清单已
> 完成，但尚未得到全量绝对正确率，因此任务1仍处于正式推理阶段。
