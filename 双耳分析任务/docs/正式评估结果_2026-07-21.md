# 任务1：同说话人双耳分听正式评估结果

**项目：双耳分析任务**

**评估日期：2026-07-21**

**模型：作者公开的 feature-gain checkpoint（`epoch=1-step=24679-v1.ckpt`）**

## 1. 做了什么

- 从Common Voice构造110名说话人的刺激。
- 每名说话人使用两条不同target录音和第三条独立cue录音。
- 左右耳呈现同一说话人的不同词，cue只放在目标耳。
- 每个目标都在左耳和右耳各评估一次，共440 trials。
- 同时评估双耳主条件、单耳零通道控制与标准diotic clean条件。
- 440条均成功完成，无无效切片和重复trial ID。

## 2. 主要结果

| 指标 | 结果 | 解释 |
|---|---:|---|
| 双耳精确命中 | **347/440 = 78.9%** | 95% Wilson CI 74.8%–82.4% |
| 对侧耳词 | **0/440 = 0.0%** | 95%区间上限0.9% |
| 其他词 | 93/440 = 21.1% | 不是左右呈现词中的任何一个 |
| 条件路由正确率 | **347/347 = 100%** | 模型只要回答了呈现词，就总是cue耳的词 |
| 单耳零通道控制 | 311/440 = 70.7% | 是输入格式控制，不是上限 |
| 标准diotic clean | 392/440 = 89.1% | 这批词在标准输入下的基线识别率 |

因为每名说话人贡献4条trial，逐trial Wilson区间未完全反映说话人内相关。使用固定随机种子、
按110名说话人进行20,000次聚类bootstrap后，双耳命中率的95%区间为73.4%–84.1%，
单耳控制为64.8%–76.4%，diotic clean为85.0%–93.2%。这不改变主要结论。

左耳命中率为79.5%（175/220），右耳为78.2%（172/220）。在220个相同目标的配对比较中，
两耳都对165、仅左耳对10、仅右耳对7、两耳都错38，没有清楚的耳侧优势。

## 3. 72.5%初步结果现在应怎样理解

旧探针的58/80（72.5%）不是代码故障，但样本较小，而且缺少匹配的识别基线。本次严格清单得到
347/440（78.9%），同时再次观察到0次对侧耳混淆。因此，旧结果的核心发现得到了支持：

> 模型的耳路由很稳定，但绝对单词识别不够高。

## 4. 为什么不能只说“78.9%都是双耳竞争造成的”

与同一trial的diotic clean结果配对后：

- 双耳与diotic clean都对：339；
- 仅双耳对：8；
- 仅diotic clean对：53；
- 两者都错：40。

这表明有两个来源：

1. **基线识别失败**：diotic clean也有48条错误，说明Common Voice切片、强制对齐或词本身难度会影响结果。
2. **双耳条件的额外损失**：在392条diotic clean可识别的trial中，双耳条件识别339条（86.5%）；
   有53条从diotic正确变为双耳错误。

单耳控制只有70.7%不是“双耳反而比单耳好”的人类听觉结论。该条件把另一通道设为零，
偏离了模型训练时的双耳输入分布，因此只能当作架构输入形式的诊断条件。

## 5. 正式结论

1. **评估管线成功**：双耳刺激、单耳cue、左右互换和评分均能正常工作。
2. **耳选择成功**：0/440对侧耳词；条件路由347/347。
3. **绝对性能未达标**：78.9%明显不是成人接近100%的水平。
4. **不直接宣称人机差异**：本实验使用自建Common Voice刺激和一个公开checkpoint，与人类数据不是
   同一组刺激，论文结果还使用了多模型汇总。

因此，最准确的一句话是：

> 任务1的技术实现和正式评估已完成；结果支持耳选择机制，但不支持模型已达到成人接近100%的绝对正答率。

## 6. 建议的下一步

### 立即做：错误审查

不根据预测结果删刺激，而是对93个`other word`错误做分层诊断：

- 优先审查“diotic clean也错”的40个共同错误：检查切片中心、强制对齐、录音质量和静音比例；
- 再审查“diotic clean对、双耳错”的53个竞争错误：比较目标词/干扰词、模型置信度和cue相似性；
- 保留所有原trial，将审查标记作为诊断列，不重算经筛选的“更好看”主结果。

### 之后的决策

- 如果目标是确认现有模型能否做双耳任务：任务1可以带着“路由成功、绝对值未达标”进入汇报，
  然后转入自训练可行性。
- 如果研究必须与成人数值直接比较：下一步必须获得或重建**与人类实验一致的刺激与评分条件**，
  不能只将当前Common Voice的78.9%与另一套人类刺激的接近100%直接相减。

## 7. 可用于日语汇报的结论

> 110名の話者から440試行を構成し、同一話者による両耳分離聴課題を評価した。
>
> 目標耳の単語を正しく出力した割合は78.9%であり、成人の100%に近い成績には達しなかった。
>
> 一方、反対耳の単語を回答した試行は0/440であり、提示されたいずれかの単語を回答した場合の耳ルーティング正確度は347/347であった。
>
> したがって、キューによる目標耳の選択は安定しているが、単語認識の絶対性能には課題が残ると結論した。
