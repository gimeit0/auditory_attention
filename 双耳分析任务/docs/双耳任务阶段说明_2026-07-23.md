# 同说话人双耳分听任务阶段说明

**项目：同说话人双耳分听模型评估（dichotic listening / 両耳分離聴）**

**记录日期：2026-07-23**

**项目位置：`双耳分析任务/`**

## 1. 本阶段要回答的问题

会议确定的任务是：左右耳同时播放**同一说话人**说出的不同语音，cue只放在目标耳，
让作者公开的feature-gain模型回答目标耳中的中央词。

本阶段主要回答两个问题：

1. 单耳cue能否让模型稳定选择正确的耳朵；
2. 模型的绝对单词识别率能否达到成人在相近双耳分听任务中接近100%的水平。

本任务使用作者公开的单个预训练checkpoint和自建Common Voice刺激。它是模型可行性评估，
不是对人类实验绝对数值的严格复现。

## 2. 刺激与评估设计

### 2.1 刺激单位

- 110名说话人；
- 每名说话人选取3条不同录音：
  - 一条作为cue；
  - 两条作为左右耳语音；
- 左右耳语音的中央目标词不同；
- 左右耳语音、cue均来自同一说话人。

### 2.2 平衡方式

每对左右耳语音生成4个trial：

- AB排列，cue左耳；
- AB排列，cue右耳；
- BA排列，cue左耳；
- BA排列，cue右耳。

因此正式评估共有：

- 110名说话人；
- 220个AB/BA目标配对；
- 440个trial；
- 左cue和右cue各220条；
- AB和BA各220条。

这种设计让同一个目标词在左右耳位置都被测量，可以减少特定耳朵、录音或单词造成的偏差。

### 2.3 三个匹配条件

每条trial使用相同的目标录音和cue计算三个条件：

| 条件 | 输入 | 用途 |
|---|---|---|
| `dichotic` | 左右耳为同一说话人的不同语音，cue只在目标耳 | 正式双耳分听 |
| `monaural_matched` | 仅目标耳有语音和cue，对侧耳静音 | 单耳输入格式检查 |
| `diotic_clean` | 目标语音复制到双耳，cue也复制到双耳 | 标准无竞争识别基线 |

左右耳语音分别归一化后组成双通道输入；单耳cue按照双耳全局RMS规则归一化。
模型的耳蜗前端接收2.5秒波形，并使用生成后中央2秒作为模型输入。

## 3. 实施过程

1. 用小样本探针检查单耳cue是否能够控制目标耳；
2. 建立同说话人、无文件重复、左右平衡的正式manifest；
3. 对440条trial运行三个匹配条件；
4. 按说话人进行bootstrap，计算正式区间；
5. 将错误分为基线共同错误和双耳特异错误；
6. 按模型实际使用的中央2秒，重新检查有效RMS、低能量比例、左右电平差和错误聚集；
7. 建立93条人工复核队列和本地听音页面。

正式评估和自动审查均可由脚本重新生成。Common Voice原始音频、checkpoint以及本地试听WAV
不进入Git仓库。

## 4. 正式结果

### 4.1 主要结果

| 指标 | 结果 |
|---|---:|
| 双耳目标词命中 | **347/440 = 78.9%** |
| 说话人级bootstrap 95%区间 | **73.4%–84.1%** |
| 对侧耳词混淆 | **0/440 = 0.0%** |
| 回答为任一呈现词时的条件耳路由 | **347/347 = 100.0%** |
| 其他词 | **93/440 = 21.1%** |
| `monaural_matched` | **70.7%** |
| `diotic_clean` | **89.1%** |
| 左cue / 右cue | **79.5% / 78.2%** |

### 4.2 与diotic clean的配对比较

| 结果组合 | trial数 |
|---|---:|
| 双耳与diotic都正确 | 339 |
| 仅双耳正确 | 8 |
| 仅diotic正确 | 53 |
| 两者都错误 | 40 |

在392条能够被`diotic_clean`正确识别的trial中，双耳条件命中339条，即86.5%。

## 5. 如何解释这些结果

### 5.1 已经得到支持的结论

**耳路由机制成立。** 440条trial中没有一次把答案报成对侧耳的中央词；当模型回答的是
左右耳实际呈现的两个词之一时，全部选择了cue指定耳的词。这说明单耳cue能够稳定控制
feature gain选择哪只耳朵。

**没有明显的模型右耳优势。** 左cue与右cue命中率接近，符合模型没有人类左半球语言优势
这一预期。

### 5.2 不能作出的结论

**不能说模型已经达到成人水平。** 78.9%的绝对命中率明显低于会议中设定的“成人接近100%”
参照，因此任务结果应表述为：

> 模型能够正确进行耳路由，但绝对单词识别性能没有达到成人参照水平。

也不能把全部93个错误都解释为双耳竞争失败。40条在`diotic_clean`中也错误，说明其中一部分
来自目标词本身、录音、模型词识别能力或标签问题；另有53条是标准diotic正确但双耳错误，
更接近双耳竞争带来的额外损失。

`monaural_matched`的70.7%不是合理的性能上限，因为它包含一个完全静音的输入通道，与模型
训练时常见的双耳输入分布不同。

## 6. 自动错误与声学审查

对模型实际使用的中央2秒重新计算后得到：

- 基线与双耳共同错误：40条；
- 双耳特异错误：53条；
- 对侧耳混淆：0条；
- 13/93条错误的目标词与预测词字符串相似度不低于0.8；
- 25/40条基线错误在diotic和双耳条件重复输出同一个错误词；
- 目标耳减对侧耳的中央2秒有效电平差中位数为0.00 dB；
- 该差值的中央95%范围为-1.79至+1.79 dB；
- 有方向电平差与命中没有明显关系（Spearman ρ=0.042，p=0.385）；
- cue低能量比例与说话人错误数没有明显关系（ρ=0.074，p=0.444）。

因此，目前没有证据表明“目标耳整体更小声”或“cue含有较多静音”是78.9%结果的主要原因。
低能量指标只是能量代理，不是语音活动检测，也不能替代人工听音。

## 7. 当前未完成事项

93条错误已经按以下顺序进入人工复核：

1. 优先检查40条基线共同错误的目标词可听度、中央对齐、转录和录音质量；
2. 再检查53条双耳特异错误的竞争影响和cue匹配；
3. 单独标记`centre → center`等可能的标签等价情况；
4. 任何排除都必须依据与模型预测无关的客观标准；
5. 原始347/440严格评分保持不变，宽松或清洗后结果只能作为独立敏感性分析报告。

人工复核表为`results/dichotic_manual_review.csv`。本地页面为
`local_review_audio/review.html`，该目录包含授权音频和浏览器状态，不上传GitHub。

## 10. 截至2026-07-23的阶段结论

任务1已经完成正式刺激构造、模型评估和自动错误审查。结果证明模型能够稳定按照cue选择正确
耳朵，但78.9%的严格单词命中率没有达到成人接近100%的参照。错误同时包含模型的一般词识别
困难和双耳竞争带来的额外损失；现有自动指标不支持静音或左右整体电平差是主要原因。

下一步是完成93条人工听音复核，并将严格主结果与标签等价/客观无效刺激的敏感性分析分开
汇报。完成该复核前，不再根据模型错误对刺激进行删除或重新筛选。
