# 同说话人双耳错误人工复核说明

**建立日期：2026-07-23**

## 1. 目的

对93个双耳错误进行与模型预测独立的人工听音核查，判断是否存在客观的切片、对齐、转录或录音质量问题。

人工复核不改变347/440的主要严格评分，也不根据“模型是否答对”删除刺激。

## 2. 已准备内容

- 93条复核记录；
- 每条4个WAV：target、opposite、cue、dichotic；
- 共372个WAV；
- 本地复核页面：`local_review_audio/review.html`；
- 源复核表：`results/dichotic_manual_review.csv`。

`local_review_audio/`受`.gitignore`保护，音频、HTML和浏览器进度不会上传到GitHub。

## 3. 听音顺序

对每条trial按以下顺序：

1. **Target**：先判断目标词是否清楚、是否位于切片中心；
2. **Opposite**：确认对侧词和录音质量；
3. **Cue**：确认cue有可听语音且无明显损坏；
4. **Dichotic**：最后听双耳刺激，但不以“自己能否立即听出”作为唯一排除标准。

## 4. 填写栏

| 栏 | 判定内容 |
|---|---|
| `manual_target_word_audible_yes_no` | 目标词是否清楚可听 |
| `manual_alignment_center_ok_yes_no` | 目标词是否在切片中心附近 |
| `manual_transcript_matches_audio_yes_no` | 转录和目标词是否与音频一致 |
| `manual_audio_quality_ok_yes_no` | 录音质量是否可接受 |
| `manual_label_equivalent_yes_no` | 如`centre→center`，预测词是否可视为标签等价 |
| `manual_exclude_for_objective_reason_yes_no` | 是否存在与模型预测无关的客观排除理由 |
| `manual_notes` | 记录听到的问题和判定依据 |

可选`yes`、`no`或`uncertain`。前四项填写后，页面将该trial计为“已完成基本判断”。

## 5. 打开方法

```bash
cd ~/projects/auditory_attention
open 双耳分析任务/local_review_audio/review.html
```

页面支持：

- 上一条/下一条；
- 跳到下一个未完成trial；
- 左右方向键切换；
- 通过浏览器`localStorage`自动保存进度；
- 导出`dichotic_manual_review_completed.csv`。

## 6. 导出与后续分析

复核完成后点击“导出已填CSV”。浏览器会下载`dichotic_manual_review_completed.csv`。

不要直接覆盖原始主结果。后续将单独汇总：

- 客观无效刺激数；
- 标签等价错误数；
- 客观问题在40个基线错误和53个双耳特异错误中的分布；
- 作为敏感性分析的宽松评分，与主要严格评分分开报告。

## 7. 重建页面

```bash
python 双耳分析任务/scripts/audit_dichotic_errors.py
python 双耳分析任务/scripts/export_dichotic_review_audio.py --all
python 双耳分析任务/scripts/make_dichotic_review_page.py
```

`audit_dichotic_errors.py`会保留已填入原复核CSV的`manual_*`栏。浏览器中尚未导出的进度只保存在
该浏览器的`localStorage`中，清除浏览器数据前应先导出CSV。
