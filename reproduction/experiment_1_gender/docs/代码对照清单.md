## 评分口径备忘（汇报常被问）
- **准确率（Fig 2b）**: 用 **exact**(`pred == 目标中间词`,`snr_scan.py` 行 144);论文用 lenient,但对本数据 exact≈lenient。
- **混淆（Fig 2e）**: 用 **lenient**(`pred ∈ 干扰句任意词`,`plot_fig2e.py` 行 58),与论文同口径。
- **已知局限**: 混淆绝对值比论文低,因 distractor 未按论文对称构造(只有 target 锚定 in-vocab 词);趋势一致。
