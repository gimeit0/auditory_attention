## 一、这次要回答的科学问题

单干扰实验已经验证：模型和人类一样，SNR 越高越听得清、异性干扰比同性容易。

这次加一个新变量：**干扰说话人的数量**。问题是——

> 在**总干扰能量固定**的前提下，干扰的**人数**增加，模型会不会也变得更难听清目标？

这考察的是**信息掩蔽（information masking）**：不是"干扰更响了"，而是"可能被混淆的声音源变多了"。人类听觉有这个规律，论文预测模型也应有。

## 二、实验设计

### 2.1 五个条件

| 条件 | 干扰说话人数 |
|---|---|
| `no_distractor` | 0（仅目标，对应 +∞ 档） |
| `one_talker` | 1 |
| `two_talker` | 2 |
| `four_talker` | 4 |
| `babble` | 8（多人叠加的持续人声底噪） |

含干扰的四个条件都在 **−9 / −6 / −3 / 0 / +3 dB** 五档 SNR 评测；`no_distractor` 是单点。

### 2.2 within-item + 嵌套抽样（保证可比性）

- **within-item**：同一批 600 个目标样本，在每种条件 × 每档 SNR 下各重混一次。条件间差异只来自条件本身，不来自"这批样本更难"。
- **嵌套抽样**：每个目标固定抽 8 个互不相同的干扰说话人 d1…d8，然后
  `one=d1｜two=d1,d2｜four=d1..d4｜babble=d1..d8`。
  → two-talker 就是 one-talker「再加一个人」，差异被干净地归因到"人数"。

### 2.3 多干扰的 SNR 归一（本实验的关键决策）

采用 **目标 vs 总掩蔽（target-to-total-masker）**：N 个干扰先各自 RMS 对齐 → 求和成一个总掩蔽信号 → 整体缩放到目标 SNR。

**为什么这样定义**：这保证 one / two / four 在同一 SNR 下**总干扰能量完全相同**。于是它们之间的性能差异**只能来自"可混淆的人变多了"**（信息掩蔽），而不是"干扰变响了"（能量掩蔽）——这正是本实验要隔离的变量。

> 内建自洽检查：N=1 时，这套流程与已完成的 Fig 2a/2b **完全等价**。

### 2.4 判据（方向对即成功）

1. 每条曲线随 SNR 上升；
2. 同一 SNR 下 **`one > two > four ≳ babble`**（人越多越难）；
3. `no_distractor` 单点显著高于所有含干扰条件（应 ≈ 88%）；
4. 混淆率反向：SNR 越低、干扰越多，混淆越高。

## 三、本阶段最重要的一项工作：重建带锚点的干扰池

### 3.1 为什么必须重建

上一阶段的 Fig 2e（混淆率）方向对了，但**绝对量级比论文低 4–5 倍**。已定位根因：

> 当时的干扰是**随机抽的**，它的中间词大多不在 800 词表内。模型即使"把干扰听成了某个词"，那个词也不在可输出的词表里，于是无法计入混淆。（18.5% 的干扰句一个表内词都没有。）

多话者实验的混淆分析会原样继承这个缺陷，且干扰越多越严重。所以**必须先修**。

### 3.2 怎么修

重建了 `distractor_pool.csv`——每条干扰录音都必须含一个**表内锚点词**，并**以该词为中心切 2.5 秒**，与目标侧的切法完全对称。这样"模型把干扰的词说出来"在原理上才可能，混淆率才有可比量级。

锚点的四个条件（与目标侧一致）：词 ∈ 800 词表 · 词长 < 2.0 s · 词前留 ≥1.25 s · 词后留 ≥1.25 s。

### 3.3 池子的自检数字（已核实）

| 项 | 值 |
|---|---|
| 池大小 | **1200 条录音 / 1200 个不同说话人** |
| 性别平衡 | 男 600 / 女 600 |
| 与目标/cue 说话人重叠 | **0**（speaker-disjoint） |
| 锚点词多样性 | **534 个不同的词** |
| 锚点率 | 58.8%（对齐 2041 条 → 收 1200 条） |
| 构建耗时 | 21 分钟 |

## 四、已交付的代码

| 文件 | 作用 |
|---|---|
| `build_distractor_pool.py` | 建带锚点的干扰池（本阶段新增） |
| `snr_scan_multi.py` | **多话者面板评测**（本阶段新增，主脚本） |

评分产出三个指标：
- `is_exact`：预测 == 目标锚点词（**准确率主指标**）
- `conf_anchor`：预测 == 某干扰的锚点词（**严格混淆**）
- `conf_sent`：预测 ∈ 干扰句表内词（**论文口径**，可直接与 Fig 2e 对比）

## 五、小样本自检（已做，但仅供确认管线，不代表结论）

在 6 个样本上试跑，确认管线跑通、结构正确：

- **准确率随 SNR 单调上升**，每个条件都是；
- **干扰人数越多越难**的趋势已显现：低 SNR 下 `one_talker` 明显好于 `two/four/babble`；
- `one_talker` 在 −9 dB 约 33%，与全量单干扰的 26% 同量级 → 说明新池子接入口径没跑偏；
- `no_distractor` = 100%（n=6 抖动），与全量的 88% 同量级。

**⚠️ 但混淆率在 n=6 下基本为 0，无法判断"带锚点的干扰池是否真的修好了 Fig 2e 的低估"。** 这是本实验唯一的未知数，**只有全量 600 样本跑完才能回答**。跑出来是多少就报多少，不提前下结论。
