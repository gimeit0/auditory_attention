## 2. 模型与任务（背景）

每个 trial，模型听两段 2 秒声音：
- **cue**：目标说话人的样本录音（"注意这个人的声音"）
- **mixture**：目标 + 干扰的混合

要输出：**mixture 里目标说话人的中间词**（从 800 词表选一个）。

**gain 机制**：每层用 cue 算增益 `g = θ1 + (1-θ1)·σ(θ2·(m_cue - θ3))`，逐元素乘到 mixture 特征上——cue 里强的特征放行、弱的压制。θ1/θ2/θ3 是训练学到、**冻结**的参数。我们只做推理。

---

## 3. 评测集构造管线（两部分共用）

对每条 Common Voice 录音：

```
强制对齐(MMS_FA) → 选锚点词 → 以锚点为中心切 2.5s → 混音(6档SNR) → 推理 → 评分
```

- **强制对齐**：torchaudio `MMS_FA`（16 kHz，字符级），得词级时间戳。
- **锚点（中间词）判定**（照论文"先选目标词、再以其为中心切片"）：
  词 ∈ 800 词表 · 词长 < 2.0 s · 词前留 ≥1.25 s · 词后留 ≥1.25 s。
- **切片**：2.5 s @ 44100 Hz = 110250 采样；模型内部再中心裁剪到 2 s。
- **diotic**：单声道复制到左右两声道（L == R，无空间线索）。
- **RMS 归一**：cue 和 mixture 都归一到 0.02（模型训练时的输入电平）。
- **评分**：`exact` = 预测词 == 目标锚点词（主指标）；`lenient` = 预测词 ∈ 目标句所有表内词。两者在本任务几乎相等。

**模型有效性验证**：44 个干净样本（无干扰）中间词识别准确率 **88.6%**，随机基线 0.1%（1/800）。全量 600 样本 +∞ 档也得 88.0%，互证。

## 4. 第一部分：Distractor sex（性别干扰）

600 样本、within-item、单干扰、diotic。**中间词识别准确率**（已从结果 CSV 核实）：

| SNR (dB) | −9 | −6 | −3 | 0 | +3 | +∞ |
|---|---|---|---|---|---|---|
| **同性干扰**（N=599） | 26.0 | 34.6 | 46.2 | 55.4 | 63.3 | 88.0 |
| **异性干扰**（N=597） | 44.4 | 53.1 | 60.1 | 68.5 | 72.5 | 88.1 |
| 异性 − 同性（百分点） | +18.3 | +18.5 | +13.9 | +13.1 | +9.3 | +0.1 |
| 差异显著性 | 6.8σ | 6.6σ | 4.9σ | 4.7σ | 3.4σ | 0.1σ |

> 误差棒（SEM）各档约 1.3–2.0 个百分点。σ = 异性−同性差异 ÷ 两者 SEM 合成。

**复现的三条趋势（对应论文 Fig 2a/2b）**：
1. 准确率随 SNR 单调上升（两条线都严格单调）；
2. 异性干扰整体高于同性（每个有干扰档高 9–18 点，3.4–6.8σ，误差棒不重叠）；
3. +∞ 无干扰时两条线收敛到约 88%（性别不再起作用）——内部一致性证据。

**Fig 2e 混淆分析**：趋势对（SNR 越低混淆越多、同性 > 异性；−9 档同性 7.2% vs 异性 1.0%），
但**绝对量级比论文低 4–5 倍**（论文同性 −9 档约 41%）。
**根因（已定位）**：干扰随机抽取，其中间词多不在词表内 → 模型即使"听成"也无法输出。
→ **第二部分修复了这个缺陷。**

图：`fig2a_reproduction_en.png` / `fig2b_reproduction_en.png` / `fig2e_reproduction_en.png`

## 5. 第二部分：Number of distractors（干扰数量）

### 5.1 设计

**条件**（7 种）：`no_distractor` / `one_same` / `one_diff` / `two_talker` / `four_talker` / `babble`(8人) / `issn`(等谱噪声对照)。
含干扰条件在 **−9/−6/−3/0/+3** 五档评测；`no_distractor` 是 +∞ 单点。

**within-item + 嵌套抽样**：同一批 600 目标，每条件×每档各重混一次；每个目标固定抽 8 个干扰 d1…d8，
`one=d1 · two=d1,d2 · four=d1..d4 · babble=d1..d8`。→ two 就是 one「再加一个人」。

**多干扰 SNR = 目标 vs 总掩蔽**：N 个干扰各自 RMS 对齐 → 求和成总掩蔽 → 整体缩放到目标 SNR。
保证 one/two/four 在同一 SNR 下**总干扰能量相同**，差异只能来自"可混淆的人变多"。N=1 时与第一部分等价（内建自洽）。

**两个防范**：
- **性别平衡**：随机抽会让 P(≥1 同性干扰) 随人数从 50% 涨到 99.6%，性别是大效应、会伪装成人数效应。
  改为按性别交替 d1…d8 → 同性数恰为 0.5/1/2/4。600 个目标全部验证：无抖动、嵌套完整、无自身/重复说话人。
- **ISSN 对照**：等谱平稳噪声（无缝隙、无内容），用来区分"信息掩蔽"和"从缝隙偷听（glimpsing）"。

### 5.2 干扰池（关键工程：`distractor_pool.csv`）

针对 Fig 2e 根因重建的**带锚点干扰池**——每条干扰录音也含一个表内锚点词、以该词为中心切片，与目标侧对称。

| 项 | 值 |
|---|---|
| 池大小 | 1200 条录音 / 1200 个不同说话人 |
| 性别 | 男 600 / 女 600 |
| 与目标/cue 说话人重叠 | 0（speaker-disjoint） |
| 锚点词多样性 | 534 个不同词 |
| 锚点率 | 58.8%（对齐 2041 条 → 收 1200 条） |

### 5.3 结果规模

`multi_talker_results.csv` = **18,600 行** = 600 样本 × 31 组（6 条件×5 档 + 无干扰单点），每格满 600。
在 **RTX 3070（CUDA）** 上跑完（M1 CPU 需约 29 小时且 MPS 不可用）。

### 5.4 准确率（prop. target word，%）

| 条件 | −9 | −6 | −3 | 0 | +3 |
|---|---|---|---|---|---|
| one_same（1人同性） | 21.0 | 30.7 | 41.2 | 49.8 | 57.0 |
| one_diff（1人异性） | 40.2 | 49.0 | 57.7 | 65.2 | 71.8 |
| two_talker | 12.7 | 20.5 | 32.0 | 46.2 | 58.0 |
| four_talker | 7.7 | 16.2 | 26.2 | 39.0 | 53.2 |
| babble（8人） | 4.5 | 12.2 | 22.8 | 40.5 | 52.5 |
| issn（噪声对照） | 10.7 | 23.0 | 44.5 | 63.8 | 71.5 |
| no_distractor (+∞) | | | 88.0 | | |

**复现的趋势**：
1. 每条曲线随 SNR 单调上升；
2. 同一 SNR 下 **one > two > four ≳ babble**（人越多越难，尤其低 SNR）；
3. no_distractor = 88.0%，与第一部分 +∞ 一致；
4. one_diff > one_same，顺带复现性别效应。

### 5.5 信息掩蔽证据（ISSN）

- **4-talker、babble 在每档 SNR 都比 ISSN 难**——而 ISSN 无缝隙、语音有缝隙；若靠"偷听缝隙"，语音本该更容易，事实相反 → **正面支持信息掩蔽**。
- **1-talker 在低 SNR 反而比 ISSN 容易**（曲线相交）——单个稀疏语音留出缝隙可偷听。

图：`fig_issn_information_masking.png`

### 5.6 混淆率（conf_sent，论文口径，%）

| 条件 | −9 | −6 | −3 | 0 | +3 |
|---|---|---|---|---|---|
| one_same | 28.0 | 20.3 | 12.7 | 7.5 | 4.5 |
| one_diff | 7.3 | 6.0 | 4.0 | 2.3 | 1.2 |
| two_talker | 19.0 | 13.7 | 8.2 | 5.0 | 2.5 |
| four_talker | 10.2 | 7.8 | 5.5 | 3.0 | 1.7 |
| babble | 7.5 | 6.3 | 3.7 | 2.3 | 1.7 |
| issn | 0 | 0 | 0 | 0 | 0 |

**两个要点**：
1. **修复成功**：同性单干扰 −9 档混淆率从旧的 **7.2%** 提到 **28.0%**（论文约 41%）。
   从"低 5.7 倍"变成"低 1.5 倍"——**根因诊断正确，修复有效**。ISSN 恒为 0（噪声无词）符合预期。
2. **一个反转（诚实记录）**：混淆率**随人数下降**（−9 档 one 28% > two 19% > four 10% > babble 7.5%），
   与计划书原假设（人越多混淆越高）**相反**，但**与论文一致**：单个同性干扰最易被"听混"；
   人一多，掩蔽退化成连续噪声，模型输出乱码而非某个具体干扰词，混淆反而降。

### 5.7 自洽性检查

- no_distractor = 88.0%，与 +∞ 锚点完全吻合；
- one_same/one_diff 贴合第一部分单干扰曲线（低 2–6 点，因换了带锚点的干扰池，属预期）；
- N=1 退化为已复现的单干扰情形，方向和形状复现 → **GPU 管线可信**。

## 6. 关键工程决策

| 决策 | 内容 | 理由 |
|---|---|---|
| 保留撇号 | 规范化正则 `[^a-z0-9' ]+` | 词表含 16 个缩写词，删撇号会对不上 |
| 锚点优先配对 | 先对齐候选、只留有锚点的做 target | 96% 产出 vs 随机配对 22% |
| 带锚点干扰池 | 干扰也以表内词为中心切片 | 修 Fig 2e 混淆率低估 |
| total-masker SNR | N 个干扰求和后整体缩放 | 让"人数"成为唯一变量 |
| 自动选设备 | `cuda if available else cpu` | Mac 用 CPU，3070/超算自动 GPU |

**已知坑**（沿用现有解法）：
- PyTorch ≥2.6 加载 checkpoint 需 `weights_only=False`（monkeypatch）；
- 新版 scipy 删了 `scipy.signal.hann` → 加垫片（须在 import 前）；
- M1 MPS 不可用：`chcochleagram` 耳蜗前端含 float64，MPS 不支持（CUDA 无此问题）。

## 7. 诚实边界与局限

1. **趋势复现，非数值复刻**（设计如此）。
2. **语料失配（CV ≠ SWC，最大的一条）**：我们用 Common Voice，论文 Experiment 1 用 Spoken Wikipedia；
   沉默习惯不同 → 沉默比例不同 → 有效 SNR 与名义 SNR 有偏差（x 轴校准）。
   且 **CV 是模型的训练语料** → 我们测**域内**，论文测**跨语料泛化**。
   → 面板内的人数趋势不受影响；**绝对量级、与 Fig 2e 的直接数值对比受影响**。
3. **混淆率仍比论文低约 1.5 倍**（已从 4-5 倍改善）。
4. **混淆随人数的方向与原假设相反**（已如实报告，非隐藏）。
5. **babble 是近似**：8 人在线求和（论文用预制文件），是保持嵌套结构的有意选择。
6. **仅 diotic**：未做空间/噪声/harmonicity 条件。
